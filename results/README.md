# Run artifacts

One directory per run: `<UTC timestamp>_<run name>_<arm>_<config hash>/`.

## Which runs are committed

Aggregate summaries — `paired_calculus/`, `sweep_*/`, `propagation_calculus/`,
the component evaluations — are **always** committed. They carry the numbers.

An individual run directory is committed when **a committed summary names its
run id**. That is the whole rule, and it follows from what the summaries are for:

- `run_paired.py` records `arms: {coupled: <run_id>, decoupled: <run_id>}`, so
  those two runs are the provenance behind a reported comparison and have to be
  reachable from it. **A summary naming a run that is not in the repository is a
  broken chain** — the number is quotable and its origin is not inspectable.
- The sweeps (`sweep_prerequisites.py`, `sweep_arbitration.py`,
  `sweep_headroom.py`) store the whole curve in the summary and name no run ids
  at all. Their per-point cohorts are therefore not referenced by anything, and
  committing them adds directories nothing reads — which makes the referenced
  ones harder to find.

So: **before committing a batch of runs, check what the summaries point at.**

```bash
grep -ho '20260[0-9]*T[0-9]*_[a-z0-9_]*' results/*/summary*.json | sort -u
```

Anything in that list belongs in the repository. Anything not in it is a working
artifact, and re-running the experiment regenerates it.

Human sittings are the exception to the rule rather than a case of it: no
summary names them, and they are committed anyway, because a sitting is a
primary observation that cannot be regenerated by re-running anything.

## Which files within a run

| File | Committed | Why |
|---|---|---|
| `manifest.json` | yes | Provenance. Small, and the only way to know what produced a number. |
| `metrics.json` | yes | Aggregated outcomes the analysis stage reads. |
| `events.jsonl` | yes | Structured event log — arbitration decisions, replanning triggers, state transitions. This is the audit log. |
| `transcript.json` | yes | Written by a human sitting only. Answers, tutor turns, what the person wrote, and the state at the end — the whole record of an observation that happened once. ⚠️ It contains the learner's own prose, and this repository is public. |
| `llm_calls.jsonl` | **no** | Raw prompt/response pairs. Hundreds of MB per cohort, and regenerable from the response cache. |
| `raw/` | **no** | Per-learner simulated transcripts. Same reasoning. |

Figures generated from these live in `results/figures/` and are committed, so
reported numbers and the artifacts they came from stay in step.

## Pooling

`agent_newton.manifest.assert_poolable` refuses to aggregate runs whose domain,
concept graph, misconception catalogue or item-bank hashes differ. If it raises,
the fix is to re-run the older arm against the current domain content — not to
bypass the check.
